## 2. Движок и ограничения

Godot 4.7.2, способ отрисовки Mobile, плагин Godot OpenXR Vendors 5.2.0. APK собирается на
GitHub Actions (см. AGENT.md, раздел 5).

Ограничения Quest 3: мобильное железо, картинка считается для двух глаз, нужно стабильно не
меньше 72 кадров в секунду. Отсюда стиль: низкополигональные модели, плоские цвета, минимум
текстур, мало источников света, мир грузится кусками вокруг игрока.

Главный риск: скорость ландшафта на шлеме. Код написан, на шлеме не измерен.

## 3. Этапы

По просьбе пользователя (2026-11-24) работа идёт без ожидания проверок на шлеме. Что проверено,
а что нет - в `docs/STATUS.md`.

### R0. Пустая сцена в шлеме - закрыт
Проверено пользователем 2026-11-24: приложение запускается без ПК, контроллеры отслеживаются,
72 кадра.

### R1. Ландшафт - написан, на шлеме не проверен
Сделан своим кодом на GDScript вместо дополнения Voxel Tools (почему - AGENT.md, раздел 2;
устройство - раздел 7): куски 8 м, копание, насыпание, выравнивание, залежи ресурсов, пещеры,
горы, дальний рельеф.
Готово, когда: на шлеме измерены кадры при ходьбе, при загрузке новых кусков и при копании,
и выбран один из исходов:
(а) скорости хватает;
(б) упрощаем: меньше дальность, крупнее ячейка, без пещер;
(в) переносим тяжёлые части на Voxel Tools или свой код на C++;
(г) переходим на Unity.

### R2. Персонаж и камера - написан, на шлеме не проверен
Персонаж от третьего лица: левый стик - движение относительно взгляда, правый - поворот вида
шагами. Камера за спиной, голова смотрит свободно. Персонаж ходит по грунту.
Готово, когда: 10 минут ходьбы без укачивания и рывков камеры.
Чего ещё нет: прыжка, бега, анимации ходьбы.

### R3. Руки и предметы - следующий этап
Луч из контроллера, захват кнопкой, предмет следует за рукой, отпускание.
Слоты с примагничиванием: рюкзак, платформа. Модели платформ со слотами уже есть (набор 4).
Самородки из грунта становятся предметами.
Готово, когда: предмет можно поднять, перенести рукой и поставить в слот.
Веха M1: три исходных требования пользователя выполнены.

### R4. Планета
Шар с гравитацией к центру, персонаж стоит по радиусу, горизонт камеры ровный в любой точке.
Ландшафт из R1 переносится на шар.
Готово, когда: планету можно обойти кругом и копать в любой точке.

### R5. Игровое ядро
Ресурсы из грунта (добыча уже считается, см. R1), кислород и тросы, простая энергосеть,
принтер, 5-10 предметов. Числа - из `docs/reference/VERIFIED.md`.
Готово, когда: с пустыми руками можно добыть ресурс, напечатать предмет и поставить его на базу.

### R6. Сохранение, меню, интерфейс
Сохранение изменений ландшафта и предметов, меню в пространстве, настройки комфорта.

### R7. Расширение
По приоритету пользователя: транспорт, исследования, вторая планета, модели по описаниям
внешнего вида образца.
