Обновлён: 2026-11-23. Текущее положение по плану - в `docs/STATUS.md`.

Играбельное ядро на Quest 3 без ПК. Полное повторение образца целью не является: его несколько
лет делала студия.

| Система | Сложность на Quest | В ядро |
|---|---|---|
| Персонаж, камера за спиной, обзор головой | низкая | да |
| Хват и перенос предметов движением контроллера | низкая | да |
| Слоты, рюкзак, платформы | средняя | да |
| Сферическая планета, гравитация к центру | средняя | да |
| Изменяемый ландшафт (копать, насыпать) | высокая, главный риск | да, в упрощённом виде |

| Кислород и тросы | средняя | да |
| Энергосеть | средняя | да, простая |
| Принтер и крафт | средняя | да, 5-10 предметов |
| Сохранение мира | средняя | да |

## 2. Движок и ограничения

Godot 4.7.2, способ отрисовки Mobile, плагин Godot OpenXR Vendors 5.2.0. APK собирается на
GitHub Actions (см. AGENT.md, раздел 5).

Ограничения Quest 3: мобильное железо, картинка считается для двух глаз, нужно стабильно не
меньше 72 кадров в секунду. Отсюда стиль: низкополигональные модели, плоские цвета, минимум
текстур, мало источников света, мир грузится кусками вокруг игрока.

Главный риск: скорость построения ландшафта. Проверяется на R1 раньше всего остального.

## 3. Этапы

Каждый этап заканчивается проверкой в шлеме, результат записывается в `docs/STATUS.md`.

### R0. Пустая сцена в шлеме
Проект: `game/` (пол, куб, бруски на месте контроллеров, счётчик кадров). Инструкция: `docs/R0_SETUP.md`.
Готово, когда: приложение запускается на шлеме без ПК, бруски двигаются вместе с руками,
счётчик показывает 72 или больше.

### R1. Проба ландшафта (решает судьбу движка)
Дополнение Voxel Tools (у него есть сборка под процессор шлема; на Quest не проверено).
Сцена: кусок гладкого воксельного грунта, копание и насыпание по кнопке контроллера,
счётчик кадров.
Готово, когда: измерены кадры на шлеме и выбран один из исходов:
(а) скорости хватает; (б) нужен свой код на C++; (в) упрощаем - поверхность без пещер;
(г) переходим на Unity.

### R2. Персонаж и камера
Персонаж-капсула от третьего лица: левый стик - движение, правый - поворот камеры.
Камера за спиной, голова смотрит свободно. Пока на плоской земле.
Готово, когда: 10 минут ходьбы без укачивания и рывков камеры.

### R3. Руки и предметы
Луч из контроллера, захват кнопкой, предмет следует за рукой, отпускание.
Слоты с примагничиванием: рюкзак, платформа. Размеры предметов и слотов - по разделу 9 справочника.
Готово, когда: предмет можно поднять, перенести рукой и поставить в слот.
Веха M1: три исходных требования пользователя выполнены.

### R4. Планета
Шар с гравитацией к центру, персонаж стоит по радиусу, горизонт камеры ровный в любой точке.
Ландшафт из R1 переносится на шар.
Готово, когда: планету можно обойти кругом и копать в любой точке.

### R5. Игровое ядро
Ресурсы из грунта, кислород и тросы, простая энергосеть, принтер, 5-10 предметов.
Числа - из справочника, раздел 18 (предложение состава ядра).
Готово, когда: с пустыми руками можно добыть ресурс, напечатать предмет и поставить его на базу.

### R6. Сохранение, меню, интерфейс
Сохранение изменений ландшафта и предметов, меню в пространстве, настройки комфорта.

### R7. Расширение
По приоритету пользователя: транспорт, исследования, вторая планета, свои модели вместо заглушек.

## 4. Сроки

Оценки грубые, ничем не проверены. Предположение: работа по вечерам, код пишут ИИ-агенты,
пользователь ставит APK и тестирует.

- R0: 1-2 вечера.
- R1: 1-2 недели.
- R2-R3 (веха M1): 2-4 недели.
- R4-R6: несколько месяцев.
- R7: без срока.
