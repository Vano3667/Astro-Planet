## Следующий шаг

Агент после ответа пользователя про шлем:

- если сцена запустилась и держит 72 кадра - закрыть R0, начать R1 (проба ландшафта:
  дополнение Voxel Tools, сцена с копанием, измерение кадров);
- если нет - исправлять по тексту `adb logcat`.

Агент, когда в `astro-planet-research` появятся данные:

1. Прочитать там `REPORT.md` и `INDEX.md`, затем `data/gaps.md`, затем остальные файлы по мере надобности.
2. Исправить и дополнить `docs/reference/MECHANICS.md`: закрыть раздел 19 «Чего не нашлось»,
   снять расхождения, убрать пометку о том, что данные взяты из выжимок поиска - для проверенных чисел.
3. В открытый репозиторий переносить только факты и числа в своей таблице. Файлы из закрытого
   репозитория целиком сюда не копировать.

Агент без ответа пользователя может: добавить иконку проекта; вывести `smoke.log` в лог задания
и посмотреть, что печатает пробный запуск.

- Числа в `docs/reference/MECHANICS.md`: взяты из выжимок поиска по двум вики. Есть расхождения
  (отмечены в справочнике).
- Названия пунктов меню шлема и телефона в `docs/R0_SETUP.md`.
- Задание `TASK.md` для локального агента: адреса API вики записаны по общим правилам MediaWiki,
  на этой вики не проверялись.
