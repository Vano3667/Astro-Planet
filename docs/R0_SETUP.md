# R0. Первый запуск на шлеме

Цель: убедиться, что собранное приложение запускается на Quest 3 без ПК.
В шлеме должны появиться пол, серый куб, два бруска на месте контроллеров и число кадров.

APK собирается на GitHub сам. Ставить Godot и Android SDK для этого шага не нужно.

Внимание: инструкция не проверялась на вашем шлеме. Названия пунктов меню могут немного
отличаться. Если шаг не сходится с тем, что на экране, - остановитесь и напишите агенту,
что именно видите.

## Что понадобится

- ПК с Windows.
- Quest 3 и кабель USB-C для передачи данных.
- Телефон с приложением Meta Horizon, к которому привязан шлем.

## Шаг 1. Режим разработчика на шлеме

1. Зарегистрируйтесь как разработчик на https://developers.meta.com/ (потребуется создать
   организацию - это бесплатно, название любое).
2. В приложении Meta Horizon на телефоне: устройства, ваш шлем, настройки шлема, Developer Mode -
   включить.
3. Перезагрузите шлем.

## Шаг 2. Программа adb на ПК

1. Скачайте архив Platform-Tools для Windows: https://developer.android.com/tools/releases/platform-tools
2. Распакуйте так, чтобы получился файл `C:\Android\platform-tools\adb.exe`.

Путь без русских букв: ваш профиль Windows называется `C:\Users\Иван`, и кириллица в пути уже
ломала программы.

Замена для тех, кому удобнее окно с кнопками: программа Meta Quest Developer Hub с сайта
разработчиков Meta. Она тоже умеет ставить APK на шлем.

## Шаг 3. Скачать APK

1. Войдите в свой аккаунт GitHub (без входа артефакты не скачиваются).
2. Откройте https://github.com/Vano3667/Astro-Planet/actions
3. Нажмите на верхний запуск «Build Quest APK» с зелёной галочкой.
4. Внизу страницы, в разделе Artifacts, скачайте `astro-planet-debug-apk`.
5. Распакуйте скачанный zip в `C:\Projects\apk`. Должен получиться файл
   `C:\Projects\apk\astro-planet-debug.apk`.

## Шаг 4. Подключить шлем

1. Подключите шлем кабелем к ПК, наденьте его и разрешите отладку по USB (поставьте галочку
   «всегда разрешать»).
2. В PowerShell:

```powershell
C:\Android\platform-tools\adb.exe devices
```

В списке должна быть строка с номером устройства и словом `device`. Если написано `unauthorized` -
разрешение в шлеме не дано. Если список пуст - кабель не передаёт данные или режим разработчика
не включён.

## Шаг 5. Установить

```powershell
C:\Android\platform-tools\adb.exe install -r C:\Projects\apk\astro-planet-debug.apk
```

В конце должно быть слово `Success`.

Если ошибка `INSTALL_FAILED_UPDATE_INCOMPATIBLE` - на шлеме стоит версия с другой подписью.
Удалите её и повторите установку:

```powershell
C:\Android\platform-tools\adb.exe uninstall com.vano3667.astroplanet
```

## Шаг 6. Запустить

В шлеме откройте библиотеку приложений, в фильтре выберите неизвестные источники
(Unknown Sources) и запустите Astro-Planet.

## Шаг 7. Что проверить и сообщить

Напишите агенту ответы по пунктам:

1. Приложение запустилось? Если нет - на каком шаге остановились и текст ошибки.
2. Видны ли пол и серый куб впереди?
3. Видны ли два бруска там, где контроллеры, и двигаются ли они вместе с руками?
4. Какое число показывает надпись перед глазами (кадры в секунду)?
5. Отвязали кабель - приложение продолжает работать?

## Если что-то не работает

Запустите приложение на шлеме, выполните команду ниже, подождите 10 секунд, остановите её
клавишами Ctrl+C и пришлите агенту вывод:

```powershell
C:\Android\platform-tools\adb.exe logcat -s godot
```

## Потом: открыть проект в редакторе (необязательно)

Понадобится, когда захотите сами посмотреть сцены.

1. Скачайте Godot 4.7.2 (обычную версию, не .NET) с https://godotengine.org/download/windows/
   и распакуйте в `C:\Tools\Godot`.
2. Скачайте проект: на странице репозитория кнопка Code, затем Download ZIP; распакуйте в
   `C:\Projects\Astro-Planet`.
3. В Godot: Import, файл `C:\Projects\Astro-Planet\game\project.godot`.
4. Плагина Quest в репозитории нет, сборка на GitHub скачивает его сама. Для редактора он ставится
   через вкладку AssetLib: найдите Godot OpenXR Vendors, версия 5.2.0.
