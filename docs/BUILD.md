## Как узнать сборку по картинкам

Пользователь может прислать картинки от старой сборки.
- Есть файлы `terrain_*.png`, самородки разной формы, у среднего ветряка широкие серые лопасти -
  сборка 45440376659 или новее.
- У среднего хранилища восемь круглых гнёзд - сборка 45444170802 или новее.
- На картинке пещеры тёмный фон вместо голубого, на серой скале нет деревьев - сборка 45447322965
  или новее.
- Пятно компаунда у старта (слева) серо-сиреневое, а не белое - сборка с новыми цветами залежей.

## Как читать сборку

1. `actions_list`, метод `list_workflow_runs`, одна запись - номер и итог последнего запуска.
2. `actions_list`, метод `list_workflow_jobs` - шаги задания (работает и пока задание идёт).
3. `get_job_logs` с хвостом 64 строки - блок между `=== SUMMARY ===` и `=== END SUMMARY ===`
   (46 строк не хватает: начало блока обрезается). Пока задание идёт, отвечает ошибкой 404.
