## Чем эта сборка отличается от прежних (чтобы узнать её по картинкам)

Пользователь может прислать картинки от старой сборки. Признаки свежей (45440376659 и новее):
- в архиве `model-sheets` есть файлы `terrain_1_start.png` ... `terrain_7_mountain_near.png`;
- самородки разной формы (гроздь шаров, соты, звезда из игл), а не одинаковые комки;
- записей `nugget resin`, `nugget organic`, `nugget ore copper` сразу после `battery small` нет;
- у среднего ветряка широкие серые лопасти.

Только в 45444170802: у среднего хранилища восемь круглых гнёзд вместо жёлтых квадратов.

## Как читать сборку

1. `actions_list`, метод `list_workflow_runs`, одна запись - номер и итог последнего запуска.
2. `actions_list`, метод `list_workflow_jobs` - шаги задания (работает и пока задание идёт).
3. `get_job_logs` с хвостом 64 строки - блок между `=== SUMMARY ===` и `=== END SUMMARY ===`.
   Пока задание идёт, отвечает ошибкой 404.
