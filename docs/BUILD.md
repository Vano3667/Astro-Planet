## Как читать сборку

1. `actions_list`, метод `list_workflow_runs`, одна запись - номер и итог последнего запуска.
2. `actions_list`, метод `list_workflow_jobs` - шаги задания (работает и пока задание идёт).
3. `get_job_logs` с хвостом 64 строки - блок между `=== SUMMARY ===` и `=== END SUMMARY ===`
   (со строками `TERRAIN_SHOT` он стал длиннее; 52 строк уже не хватает).
   Пока задание идёт, отвечает ошибкой 404.
