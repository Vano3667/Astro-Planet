## Как прочитать итог следующей сборки

`=== SUMMARY ===` и `=== END SUMMARY ===`. Пока задание идёт, лог не отдаётся (ошибка 404);
готовность видно по полю `status` запуска. Строки `MODEL <id>` с размерами моделей в сводку не входят.
