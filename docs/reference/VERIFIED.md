# Числа образца, проверенные по вики

Источник: закрытый репозиторий `Vano3667/astro-planet-research`, файл `data/gaps.md`, собран
локальным агентом 2026-11-24 с astroneer.wiki.gg через API. Здесь только факты и числа.
Если число расходится с `MECHANICS.md`, верным считать это.

Названия предметов даны по-английски, как на вики; в игре они заменяются своими.

## Кислород

| Параметр | Значение |
|---|---|
| Запас рюкзака в покое | 72 с или 72,5 с (две страницы вики дают разное) |
| Запас рюкзака на бегу | 45-50 с (две страницы вики дают разное) |
| Дополнительный баллон | столько же, сколько основной запас |
| Предупреждения | на 50 % и на 25 % шкалы |

## Чего на вики нет совсем (задаём сами)

1. Скорость ходьбы и бега, высота прыжка.
2. Порог и величина урона от падения.
3. Расстояние между тросами и длина кабеля в метрах.
4. Время печати по принтерам и предметам.
5. Радиус и скорость инструмента для грунта.
6. Объём одной порции грунта.
7. Размеры предметов и слотов в метрах.
8. Радиусы планет и сила тяжести.
