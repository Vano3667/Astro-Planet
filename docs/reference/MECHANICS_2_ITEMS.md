## 8. Ресурсы

Природные (добываются копанием): Compound, Resin, Organic, Clay, Quartz, Graphite, Ammonium,
Laterite, Malachite, Sphalerite, Wolframite, Hematite, Titanite, Lithium, а также грунт и
редкое вымышленное вещество из ядра планет.

Плавка в печи (1 к 1, 15 с на самородок):

| Сырьё | Результат |
|---|---|
| Organic | Carbon |
| Clay | Ceramic |
| Quartz | Glass |
| Laterite | Aluminum |
| Sphalerite | Zinc |
| Malachite | Copper |
| Wolframite | Tungsten |
| Hematite | Iron |
| Titanite | Titanium |

Газы (конденсатор атмосферы): Hydrogen, Argon, Methane, Nitrogen, Helium, Sulfur.

Составные (химлаборатория):

| Результат | Состав |
|---|---|
| Rubber | Organic + Resin |
| Plastic | Carbon + Compound |
| Aluminum Alloy | Aluminum + Copper |
| Tungsten Carbide | Tungsten + Carbon |
| Hydrazine | Ammonium + Ammonium + Hydrogen |
| Graphene | Graphite + Hydrazine |
| Diamond | Graphene + Graphene |
| Silicone | Resin + Quartz + Methane |
| Explosive Powder | Carbon + Carbon + Sulfur |
| Steel | Iron + Carbon + Argon |
| Titanium Alloy | Titanium + Graphene + Nitrogen |
| Nanocarbon Alloy | Titanium Alloy + Steel + Helium |

## 9. Размеры предметов и слоты

| Размер | Уровень | Сколько малых слотов занимает |
|---|---|---|
| Малый | 1 | 1 |
| Средний | 2 | 2 соединённых |
| Большой | 3 | 4 соединённых |
| Очень большой | 4 | 8 соединённых |

- Малый предмет встаёт в любой слот. Предмет крупнее требует слот своего размера или больше.
- Самородок ресурса - малый предмет.
- Печать расходует ресурсы постепенно, по мере хода печати.
- Упаковщик (Packager, рецепт Graphite) сворачивает установленный предмет обратно в коробку.

Платформы:

| Платформа | Слоты | Рецепт |
|---|---|---|
| Средняя A | 1 средний | Resin |
| Средняя B | 1 средний + 2 малых | 2 Resin |
| Средняя C | 1 средний | Resin |
| Средняя T | 2 средних, 3 разъёма кабеля | 2 Resin |
| Высокая (Tall) | 1 средний + 4 малых | Ceramic |
| Большая A | 1 большой | 2 Resin |
| Большая B | 1 большой + 2 средних | 3 Resin |
| Большая C | 1 большой + 20 малых | Resin + Iron + Ceramic |
| Очень большая A | 2 больших | 2 Iron + 2 Ceramic |
| Очень большая B | 1 очень большой | 4 Iron |
| Очень большая C | не найдено | 2 Resin + 2 Iron |

У платформ A по 4 разъёма кабеля.

## 11. Принтеры и рецепты

Цепочка: принтер в рюкзаке печатает малые предметы, малый принтер - средние, средний - большие,
большой - очень большие. Каждый следующий принтер печатается на предыдущем.

В рюкзаке (малые предметы):

| Предмет | Рецепт | Открытие |
|---|---|---|
| Связка тросов | Compound | сразу |
| Малая канистра | Resin | сразу |
| Малый генератор | Compound | сразу |
| Маяк (Beacon) | Quartz | сразу |
| Фонарь (Worklight) | Copper | сразу |
| Малый принтер | Compound | сразу (по памяти агента) |
| Светящиеся палочки | Organic | 350 байт |
| Малая солнечная панель | Copper | 300 байт |
| Малая батарея | Zinc | 2000 байт |
| Кислородный баллон | Glass | 2000 байт |
| Анализатор грунта | Zinc | 2000 байт |
| Динамит | Explosive Powder | 3750 байт |
| Переносной генератор кислорода | Nanocarbon Alloy | 10 000 байт |

Малый принтер (средние и часть малых): средний принтер (2 Compound), генератор кислорода
(Ceramic + Aluminum), платформы и хранилища среднего размера, трактор, сиденье ровера (2 Compound),
средний силос (2 Titanium), средняя солнечная панель, средний шредер (2 Iron), полевое укрытие
(Graphene + Silicone), манипулятор (Graphite + Aluminum), упаковщик (Graphite), средние канистры,
буры, двигатели шаттла.

Средний принтер (большие предметы):

| Предмет | Рецепт |
|---|---|
| Большой принтер | 3 Compound |
| Исследовательская камера | 2 Compound + Resin |
| Плавильная печь | 2 Resin + Compound |
| Центрифуга грунта | 2 Compound + Aluminum |
| Химлаборатория | Tungsten + Glass + Ceramic |
| Конденсатор атмосферы | Iron + Glass + Plastic |
| Большие платформы A / B / C | см. раздел 9 |
| Большое хранилище | 3 Ceramic |
| Большая солнечная панель | Aluminum Alloy + Glass + Copper |
| Большой ветряк | Aluminum Alloy + Glass + Ceramic |
| Багги | Compound + Aluminum |
| Средний ровер | 2 Plastic + Rubber |
| Большое сиденье ровера | 2 Plastic + Compound |
| Кран | Titanium + Silicone + Steel |

Часть рецептов этого принтера требует особой детали (EXO Chip), которую нельзя напечатать:
торговая платформа, большой шредер.

Большой принтер (очень большие предметы): укрытие (2 Silicone + 2 Plastic), малый шаттл (2 Aluminum),
средний шаттл (2 Ceramic + Aluminum Alloy), большой шаттл и большой ровер (нужна особая деталь),
солнечный массив, очень большие платформы, очень большое хранилище, посадочная площадка.

Расхождения в выжимках: трактор - «Aluminum + Rubber» или «2 Aluminum»; печь и центрифуга в одной
выжимке отнесены к большому принтеру, в двух других - к среднему (в таблице выбран средний).
