# AGENT.md - точка входа для агента

Этот репозиторий открытый и держит **только инструкции для агентов**. Кода игры, моделей и данных
образца здесь нет и не будет.

**Правило размера (читай первым).** Файлы больше **12 000 байт не создавать**: в длинной беседе
такой файл до агента не доходит. Текст делить на части заранее. Если файл не дошёл, не гадать и не
переделывать по памяти: сказать пользователю, что нужна новая беседа.

## 0. Где что на самом деле

| Что | Где |
|---|---|
| Актуальный код игры (Godot 4, Quest 3) | только на компьютере владельца (локальный клон, ветка `local-assets`) |
| Рабочие заметки и результаты агентов | закрытый репозиторий `astro-planet-research` (папка `hub/`), потом на компьютере |
| Инструкции для агентов | этот открытый репозиторий |

Старый код и старые документы (`game/`, `docs/STATUS.md`, `BUILD`, `REVIEW`, `PLAN`, `JOURNAL`,
`reference/`, `review/`, `status/`, сборка APK) удалены из рабочего дерева как устаревшие, но остались
в истории git. Ссылки на них внутри `docs/agent/A1-A5` устарели: не искать их и не восстанавливать
без слова владельца.

## 1. Порядок чтения

1. Этот файл.
2. Если у тебя есть доступ к закрытому `astro-planet-research`: в нём `hub/README.md`, затем `hub/STATE.md`.
   Если доступа нет, скажи пользователю и не гадай о состоянии проекта.
3. Затем `docs/agent/A1_PROJECT.md`, далее по теме: `A2_REPO_BUILD`, `A3_MODELS`, `A4_MODELS_VIEW`, `A5_TERRAIN`.

## 2. Суть проекта

Своя VR-игра для Meta Quest 3/3S (без ПК в шлеме) на Godot 4. Повторяет ядро механик ASTRONEER своим кодом.
Игра личная, не для распространения. Изначальные требования:

1. камера за спиной персонажа со свободным обзором головой;
2. управление контроллерами;
3. перемещение предметов движением контроллеров.

Пользователь - начинающий: базовое программирование, без опыта в игровых движках.
Объясняй простым языком, давай готовые команды, не пропускай шаги. Отвечай по-русски.

## 3. Правила работы

- Код игры в этот открытый репозиторий не класть. Коммит и пуш кода игры только по явному слову владельца.
- Всё, что извлечено из игры-образца (меши, текстуры, звук, выгрузки логики, таблицы), не кладётся
  в этот репозиторий и в APK, собранный на GitHub. Для выводов агентов есть закрытый репозиторий.
- Не клади сюда токены, ключи, пароли, файлы `*.keystore`, скриншоты и тексты вики.
- Разделяй уровни проверки: «написано», «собирается локально», «проверено скриптом без шлема»,
  «агент видел буквенную схему картинки», «проверено на шлеме». Сборка без ошибок не значит, что
  игра работает в шлеме. Никогда не пиши, что видел картинку, если видел только текст.
- Пункты, о которых владелец не говорил, помечай «не сообщалось». Написанное по памяти помечай
  «по памяти». Не выдумывай API движка и плагинов.
- Числа, которых нет в источниках (скорость, радиусы, размеры), задаются своими и помечаются
  словами «Own values».
- Названия из оригинала (планеты, вещества, оборудование) в самой игре можно заменять своими.
- У облачного агента ограничено число действий за один ответ. Не опрашивай сборку в цикле.
- Для `push_files` SHA не нужен. Для `create_or_update_file` нужен текущий SHA файла.
- Работа на компьютере владельца: `run_command` требует одобрения. Не повторяй после таймаута.

## 4. Какой файл о чём

| Файл | Что внутри |
|---|---|
| `AGENT.md` | этот файл |
| `docs/agent/A1_PROJECT.md` | решения, управление, данные с вики, кто что может, окружение, формат журнала |
| `docs/agent/A2_REPO_BUILD.md` | структура репозитория и сборка (в том виде, как была раньше) |
| `docs/agent/A3_MODELS.md` | устройство моделей, конструкторы, палитры |
| `docs/agent/A4_MODELS_VIEW.md` | витрина, просмотр картинок, описания внешнего вида |
| `docs/agent/A5_TERRAIN.md` | грунт, залежи, копание, пещеры |

Файлы `A2`-`A5` описывают старое устройство кода, которого здесь больше нет. Актуальное
устройство смотри в локальном клоне и в `hub/STATE.md` закрытого репо. При расхождении прав локальный код.
