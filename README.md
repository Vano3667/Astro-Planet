# Astro-Planet

Своя VR-игра для Meta Quest 3 на Godot 4, работает на шлеме без ПК.
Жанр: песочница на небольшой планете - копать грунт, носить предметы руками, ставить их в слоты,
следить за кислородом и энергией, печатать оборудование.

Вид от третьего лица: камера за спиной персонажа, головой можно смотреть в любую сторону,
управление контроллерами Touch, предметы переносятся движением контроллера.

**Статус:** самое начало. APK собирается на GitHub автоматически, но на шлеме ещё ни разу не запускался.
Актуальное состояние: [docs/STATUS.md](docs/STATUS.md).

## Как получить APK

Вкладка [Actions](https://github.com/Vano3667/Astro-Planet/actions), последний зелёный запуск
«Build Quest APK», внизу раздел Artifacts, файл `astro-planet-debug-apk`.
Как поставить его на шлем: [docs/R0_SETUP.md](docs/R0_SETUP.md).

## Правило об ассетах

Игра вдохновлена ASTRONEER, но это отдельный проект. Модели, текстуры, звуки, иконки, тексты
и названия из неё в репозиторий не попадают. Графика своя или со свободной лицензией (CC0).
