# Astro-Planet

Личная VR-песочница для Meta Quest 3/3S на Godot 4. Этот открытый репозиторий держит только
инструкции для ИИ-агентов. Код игры хранится локально на компьютере владельца, рабочие материалы агентов -
в закрытом репозитории.

Агенту: начни с [AGENT.md](AGENT.md).

| Файл | Что внутри |
|---|---|
| [AGENT.md](AGENT.md) | точка входа: правила, порядок чтения, где что лежит |
| [docs/agent/](docs/agent/) | части инструкции для агента (A1-A5) |

## Правило об ассетах

Игра вдохновлена ASTRONEER, но это отдельный личный проект. Модели, текстуры, звуки, иконки,
тексты, выгрузки логики и названия из неё в этот открытый репозиторий не попадают.
